StatusBoost .NET#

See the status of your Exeltech power systems from your Windows PC.

Download StatusBoost .NET

Version 2.0.11 · Windows 10 and 11, 64-bit · 44 MB · Free for Exeltech customers · License

Install it

  1. Open the file you downloaded, StatusBoost.NET-2.0.11-x64.msi.
  2. Follow the installer. When Windows asks for permission, click Yes.
  3. Start StatusBoost .NET from the Start menu or the desktop.

The user guide is built into it: open Help, then User Guide.

If Windows says “Windows protected your PC”, click More info, then Run anyway. This version is not digitally signed yet.

Alarm Configuration Tool#

Choose which conditions raise your Exeltech unit's alarms, and which module slots and cages it has.

Download Alarm Configuration Tool

Version 2.0.6 · Windows 10 and 11, 64-bit · 50 MB · Free for Exeltech customers · License

By downloading it, you accept its license.

Run it

  1. Put ConfigurationTool.exe in a folder of its own, for example in your Documents.
  2. Open it. It needs no installation and no administrator rights.

Close StatusBoost while you use the tool: both use the same network port to find units. Its User Guide button opens the guide built into it.

If Windows says “Windows protected your PC”, click More info, then Run anyway. This version is not digitally signed yet.
