# Exeltech Software Downloads

| Item | Link |
|---|---|

| Alarm Configuration Tool | <https://unumaleum.github.io/downloads/#alarm-configuration-tool> |

| SNMP MIB for KC Systems | <https://unumaleum.github.io/downloads/#snmp-mib> |

## What is here

- **The programs** are this repository's [releases](../../releases), one tag per program and version (for example `statusboost-2.0.7`).
- **The files**, such as the user guide, the MIB and the licenses, are in [`docs/files/`](docs/files). They keep the same name from version to version, so a link to one keeps working.
- **The page** is `docs/index.html`, published by GitHub Pages. It is generated, so don't edit it by hand.
