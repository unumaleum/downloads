## What is here

- **The programs** are this repository's [releases](../../releases), one tag per program and version (for example `statusboost-2.0.14`).
- **The files**, such as the user guides, the MIBs and the licenses, are in [`docs/files/`](docs/files). They keep the same name from version to version, so a link to one keeps working.
- **`docs/versions.json`** lists each program's current version, for StatusBoost's Check for Updates.
- **The page** is `docs/index.html`, published by GitHub Pages at the address above. It is generated, so don't edit it by hand.
